# AIJiYi 当前功能清单

核对日期：2026-11-02。依据是本仓库的入口、路由、实现和测试；“存在”指代码可调用，不等于本机外部服务、模型、账号或平台已就绪。历史审计和设计文档按写作日期阅读。

本次基线：`python -m unittest discover -s tests`，442 项运行、1 项跳过；运行时关闭了自动 MCP 研究与表情包定时更新，以免测试启动外部网络循环。测试仍输出部分 socket 资源警告。

## 1. 记忆与认知

| 功能 | 当前实现与边界 |
|---|---|
| 多身份记忆 | 按平台、用户 ID、scope 隔离；登记账号、保存会话原文、画像、表达风格、事实、知识、关系、摘要、媒体引用和注入记录。 |
| 异步学习 | 用户轮次与媒体识别结果进入写队列；模型抽取不可用时有本地规则兜底。写入有来源、置信度和审计记录；`/flush` 可等待落库。 |
| 事实维护 | 同值合并、多值累积、单值替换、否定失效；保留历史和事实关联。支持显式遗忘、按时间回查、冻结低活跃事实及读取后强化。复杂语义矛盾仍受规则和模型抽取质量限制。 |
| 召回与注入 | 关键词/FTS 召回、时间与重要度排序、一跳关联、可选 hash/hybrid 向量索引；注入带来源且有长度预算。`weighted` 默认，RRF 是可选排序模式。注入只生成上下文，不直接生成回复。 |
| 反馈与纠错 | `feedback` 接受注入 ID、使用的事实 ID 和无帮助标记，更新命中统计；需要调用方回报，不能把“有接口”当作所有接入都已形成闭环。 |
| 摘要与归档 | 会话摘要优先用配置的模型，失败退回本地压缩；超长会话原文先归档再压缩，归档保留期内可查。 |
| 自我记忆与反思 | 独立保存自我偏好/经历，按相关性少量注入；后台反思、性格特征和自我画像有实现。角色物理边界与出口闸门参与对话。 |
| 多模态识别 | 文本、emoji、图片 OCR、语音 ASR、文件文本、网页标题、视频元数据。图片和语音需要可用引擎；自动 OCR 支持字节、批量字节和可访问 URL。视频只记录元数据。无引擎或低置信度时如实返回状态。 |
| 记忆代谢 | 清理器有冻结、去重、关联上限、归档清理等规则；额度与弃答/排序策略由配置决定。 |

## 2. 对话与接入

| 功能 | 当前实现与边界 |
|---|---|
| OpenAI 兼容对话 | `GET /v1/models`、`POST /v1/chat/completions`；支持非流式和 SSE 格式，身份请求头及 `user` 提示、可选服务端历史补全、采样参数、记忆注入、模型池、角色闸门、异步写回。当前 SSE 是完整响应分块输出，不代表上游逐 token 流式推理。 |
| 统一 IM 网关 | `POST /v1/gateway/messages` 接收归一化消息并返回回复及诊断信息；`POST /v1/gateway/onebot` 接收 OneBot 事件。 |
| OneBot / QQ | 内置 OneBot 客户端、事件解析、群聊 @ 判断、队列发送、心脏层 outbox/重试/租约与调度器。实际 QQ 收发需要 NapCat 等外部服务、账号及正确配置。仓库外的 AstrBot 插件行为不属于本仓库已验证功能。 |
| Octop Gateway | 有独立适配模块；需要安装可选 `im` 依赖和外部网关。 |
| 主动消息 | 有主动策略、静默/冷却/额度逻辑和服务内配额接口；是否真正向群聊主动发送取决于接入方与运行配置。余额读取不到时可手填积分，费用换算依赖模型价格。 |
| 操作工具 | 文件读取/列表、受控写入、终端、桌面截图/点击/按键工具和人工审批管理。具体可用性由平台、策略和审批决定。 |
| 鉴权 | 设置 `AIJI_API_KEY` 后，`/v1/*`、`/api/*` 及核心数据接口要求 Bearer key；`/health` 与静态页面公开。默认服务监听 `127.0.0.1`。 |

## 3. 本地界面

| 功能 | 当前实现与边界 |
|---|---|
| 运行与功能页面 | 取代旧 15 页控制台；展示 22 项实际能力、实时状态、功能详情与常用操作表单。配置可分组保存到 `config/runtime.json`（可恢复单组默认），重启后生效。**启动与结束**页按依赖链实测五项服务：端口 / PID / 进程名 / 已建立连接、卡点与处置建议、启动前置检查（Python、AstrBot、NapCat、QQ、配置）、登录启动项与 `AIJiYi Console Watchdog` 保活任务（可在页面注册/注销）、`data/lifecycle.log` 尾部；启停下发后每 2 秒复查真实端口直到就绪或 90 秒超时。页面也可用 `file://` 直接打开（服务端仅放行 `null` 与 `127.0.0.1:8787` 两个本地来源的 CORS）。QQ 客户端保持打开。 |
| 工作区 | 浏览、读取和写入工作区文件，默认关闭，需 `AIJI_ENABLE_WORKSPACE=1`；终端另需 `AIJI_UNSAFE_SHELL=1`，命令本身不受路径沙箱约束。 |

## 4. 生活、媒体与联网服务

| 功能 | 当前实现与边界 |
|---|---|
| 生活状态 | 精力、压力、情绪、私人笔记、生活事件、受控活动循环、生命卡和体检接口；活动循环不自行执行 QQ 空间、文件或终端操作。部分生命卡引擎是独立算法，不能等同于已接入每轮生产对话。 |
| 语音 | 声线注册与切换、`/v1/audio/speech`、Edge TTS、Windows SAPI、GPT-SoVITS、CosyVoice、OpenAI 兼容/模板 HTTP TTS、Seed-VC 换声接口；各引擎需相应依赖、服务和声线文件。 |
| 唱歌 | 歌曲搜索、排队、截段、伴奏/人声分离、换声、混音和音频结果接口；需要外部工具和可用音源。 |
| QQ 空间与分享 | 发表动态、评论、自动评论、头像、签名、音乐与哔哩哔哩分享接口；通过已配置的 OneBot/NapCat 扩展 action 执行。 |
| 表情包 | 本地图库、远程公开 feed 合并、单图 URL 导入、定时更新及状态接口；远程下载受公网地址和文件格式检查约束。 |
| MCP 研究 | 白名单只读 MCP 客户端、候选仓库发现与报告、手动触发和定时循环；默认配置中的外部 MCP 程序、GitHub API 与网络必须可用。发现结果不会自动安装。 |

## 5. 使用与诊断入口

- CLI：`serve`、`remember`、`ingest`、`recall`、`inject`、`feedback`、`style`、`media`、`accounts`、`stats`、`doctor`、`export`、`forget`、`archive`、`self-memory`、`quota`、`bench`。
- 核心 HTTP：`/turns`、`/remember`、`/ingest`、`/media`、`/recall`、`/inject`、`/feedback`、`/flush`、`/style`、`/accounts`、`/stats`、`/being`、`/being/note`、`/being/event`、`/health`。
- 控制台 API：记忆库/关系图/自我/调度器/模型/能力/近期对话/注入记录/主动状态/生命卡/审批/OneBot/文件工作区，以及语音、歌曲、社交、表情包与 MCP 接口。细节以 `aiji/throat/server.py` 路由和参数为准。
- 测试和诊断：`tests/` 的单元测试、`bench/` 性能与质量脚本、`tools/` 的引擎/现场/迁移/验收探针。探针是维护工具，不自动代表对应外部集成已上线。

## 当前限制

模型池、真实 OCR/ASR、语音引擎、QQ、MCP、音乐来源和远程表情包均依赖外部服务或可选包。生产链路是否真的经过某个模块，应以当前运行日志和数据为准；历史现场审计不能推断 2026-11-02 的在线状态。旧设计文档中的计划、未接线算法和历史故障不计入“当前已可用”的无条件功能。
