# 大肥鱼行为逻辑 v1

目标不是继续堆人格提示词，而是把截图里的“交流层 / 生活层 / 情绪层”变成持续状态。

## 交流层

已实现：

- 短句、口语、无 Markdown、无客服腔：`selfhood.py`。
- 热聊 / 普通 / 冷启动 / 急事四档首字延迟：`humanize.py`。
- 精力低时回复更慢、提示词要求更短。
- QQ 长文本默认按句拆条，减少一整段文字墙。
- 正文 emoji/表情标记会被剔除；本地表情包按情绪独立发送。
- 群聊默认 `auto`：@、引用、叫名字必回；其余按概率、兴趣词、冷却和静默时段。
- 引用、图片、语音、历史群上下文都进入同一条消息语义链。
- 刚上线 30 分钟内，模型知道“刚上线”，但不强制播报。

## 生活层

已实现：

- 角色全局状态独立于联系人和群：精力、情绪、社交电量、压力、上线时间。
- 精力白天消耗、夜间恢复；连续交流消耗，社交电量不足会降低主动意愿。
- 每次互动只写入情绪余波，不再把用户原话伪装成她自己的经历。
- `LifeLoop` 独立按时间推进受控活动，记录她自己的 `self_activity`，保存当前
  活动、焦点、结束时间和下一次触发时间。
- 活动间隔默认 14-60 分钟，服务每 60 秒检查一次；低精力时只会休息，夜间才会
  睡觉，不会在白天随机“睡过去”。
- 主动消息会拿到当前活动和她自己的近期经历，可以自然接上正在做的事。
- 私密 `being_note` 只进入角色提示词，不写进用户事实；模型不得直接照念。
- 主动消息使用 `remember=false + proactive=true`，不会把系统生成的话写成用户发言。
- 主动生成受精力、社交电量、静默、冷却和每日额度共同限制。

外部动作边界：

- QQ 空间、头像、签名、音乐、B 站分享通过 NapCat 扩展 OneBot action 执行；
  未配置 `AIJI_ONEBOT_API` 时明确返回 `social_not_configured`，不伪造成功。
- 可以通过 `/being`、`/being/note` 读取状态或写入私密记录；`/api/social/*`
  负责显式平台动作。

## 情绪层

已实现：

- 情绪区间 `-20 ~ 20`，带惯性衰减，不永久记仇。
- 争吵、压力、安慰、夸奖、亲密会改变情绪和压力。
- 长时间无互动会形成轻微低落，但有上限，不会无限累积。
- 当前心情、精力、最近生活事件和私密本子进入模型提示。
- 低精力、夜间或社交电量不足时，主动消息可直接跳过模型。
- Edge TTS 支持音色、语速、音高、音量四项定制。
- 物理底线、不可越权、可以拒绝的边界仍在 `selfhood.py`。

## 状态接口

```text
GET  /being              # 当前活动/精力/情绪/生活事件/私密本子/循环统计
POST /being/note         # 写入只属于角色自己的私密记录
POST /being/event        # 外部生活痕迹：QQ空间、音乐、日记、B站等
POST /v1/chat/completions
     aiji.remember=false
     aiji.proactive=true
```

`/being*` 与 `/turns`、`/api/*` 一样受 `AIJI_API_KEY` 保护。

## 设计来源

- `dsh-roost`：情绪读数、精力、日记、主动搭话需有“不说话”的出口。
- `dsh-qq-bridge/companion-mood.js`：短时情绪置信度、半衰期、当前问题优先。
- `dsh-aurabot-qq`：情绪/精力影响表达和主动行为。
- `dsh-im-humanize`：发送延迟、消息拆分、拟人节奏。
- `dsh-split-reply`：长回复按句拆条。

## 尚未接管
