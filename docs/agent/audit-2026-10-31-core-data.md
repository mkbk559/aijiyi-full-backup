# AI 核心与数据审计（2026-10-31）

## 结论

当前 AI 核心不是“已经像人”，而是“有拟人外壳和行为状态的智能体”。
它已经能持续记忆、表现出情绪余波、按时间推进生活活动、控制回复长度和节奏；
但人格、称呼、反思和输出规则同时存在多套来源，确实会造成自相矛盾。

问题不是所有措施都没用，而是这些措施没有共享同一份“当前事实”：

- `selfhood.py` 写物理底线和通用说话规则。
- `persona.py` 再写一层孙吧式语气。
- `reflect.py` 从用户和机器人自己的历史回复里学习习惯。
- `style` 表学习用户表达方式。
- `fact` 表保存用户昵称和偏好。
- `Head` 再把平台昵称、注入记忆、生活状态和人格提示拼在一起。

只要其中两层给出不同称呼或风格，模型就会“人格分裂”。提示词里再多写一遍
“不要矛盾”，也压不住互相冲突的数据。

## 本次已修复

3. **表达规则自相矛盾**

     但不要用反问把话抛回去”。

     但不会声称自己是人类”。

6. **昵称/头像只作展示标签**
   - 账号主键仍是 `(platform, platform_user_id)`，QQ 号不因昵称或头像改变。
   - 新增账号标签落库：`display_name` 保存昵称，`account.extra.avatar` 保存头像 URL。

7. **测试身份清理**
   - 已备份并清理 24 个明确测试身份；删除 22 个 account、21 条 fact、
     80 条 turn、36 条 trait、25 条 life_card 等测试数据。
   - 真实 QQ `2216608312`、`2221813100` 保留。
   - 账号展示名已从最新用户轮次回填：`玛卡巴卡`、`相逢太短，不等茶凉`。
   - 历史私聊 media 的 `scope=private` 已迁移成 `default`。

8. **全局人格 / 关系型适应拆分**
   - 同一习惯必须在至少两个独立身份/关系中重复出现，才进入“稳定底色”。

   - 这避免一个群里的梗被带到所有关系，也避免每个联系人各自把机器人养成不同人格。

## 已发现但仍需处理

### P1：旧昵称历史仍保留

最新昵称已经通过读取规则和提示词优先级解决，旧行仍保留作历史审计。
若需要彻底清理，可以把旧 `主人` 事实标为 `superseded`，但这不阻塞当前行为。

### P2：反馈闭环实际没有启动

`injection=130`，但 `feedback` 全是 `NULL`。因此“命中计数让召回更准”这条链路
目前没有真实数据支撑。需要下游明确回报 `used_ids`，或根据最终回复自动标注。

### P2：会话键仍可能分裂

同一 QQ 私聊同时存在 `default` 和 `private:<QQ号>` session。身份没有错，但
历史上下文会被拆成两个会话。需要所有入口遵守同一规则：

- 私聊：`scope=default`，`session=private:<QQ号>`
- 群聊：`scope=group:<群号>`，`session=group:<群号>`

### P2：全局人格仍需要真实数据积累

底层 trait 仍按联系人存储，但运行时已拆成：

- `global trait`：至少跨两个关系重复出现，进入稳定底色。
- `relationship trait`：当前联系人/群里的局部变化。
- 当前即时情绪：仍由 `being_state` 管。

当前真实库里尚未形成跨两个真实关系重复的全局 trait，因此稳定底色为空。
这是数据量不足，不是故障；继续互动后才应自然出现。

- `data/console.err.log` 有进程 abort 记录。
- `data/pet.log` 有 DSH profile bundle 不兼容记录。

## 项目现在能做什么

- 分层记忆：事实、画像、风格、关系、摘要、注入留痕、反馈。
- 多平台身份隔离：`platform + QQ号/用户号 + scope`。
- QQ 群/私聊接入：OneBot 消息、非 @ 入库、长回复拆分、独立表情包。
- OpenAI 兼容入口和本地控制台。
- QQ 空间发说说、评论、自动选最新说说评论。
- QQ 头像、签名、音乐分享、B 站分享。
- Edge TTS、Open-LLM 兼容 TTS、GPT-SoVITS v2、CosyVoice SFT/零样本/跨语种。
- 歌曲截段、人声分离、Seed-VC 换声、混音。
- 本地+联网图库：远程 feed、自动更新、图片校验、原子写入、插件热重载。
- 情绪、精力、社交电量、生活事件、主动消息、生活活动循环。
- 受控文件/终端/桌面工具和人工审批。
- 研究型 MCP 只读发现，不自动安装。

## 目前不具备

- 真正的人类意识或稳定“自我”；当前是状态机 + 记忆 + 提示词约束。
- 跨会话统一的全局人格基线。
- 可靠的图片语义理解、视频理解、实时打断/VAD。
- 自动判断哪条好友动态值得评论；当前只按指定 QQ 和 `post_index` 选。
- 完整隐私分层：昵称、头像、QQ号、聊天原文当前都在同一 SQLite。
- 自动数据治理：测试身份、重复会话、过期 cache 仍会堆积。

## 成精体检结论（真实模型探针）

新增四层体检接口和临时数据库探针：

- 皮囊层：规则/出口/节奏确定项通过；真实自然度仍需抽样，因此只算部分通过。
- 骨肉层：物理底线、QQ 号昵称优先、trait 分层、反思防污染均通过。
- 血脉层：多巴胺/皮质醇方向、低精力主动退避、心境影响上下文均通过。
- 灵魂层：多跳联想、触景生情、群友意外感未自动认证。

真实模型三探针发现并修复了两个问题：

1. 面对写代码请求曾直接输出可运行 Python；现在 IM 角色空间会触发物理动作
   边界并拒绝，桌面平台仍保留编码能力。
2. 模型曾把用户昵称“玛卡巴卡”误当成自己的名字；现在输出层会纠正
   “我是<用户昵称>”，并在提示词中明确“称呼对方”与“自己叫大肥鱼”分离。

体检不会因为正则初筛通过就宣布成精；最终判断仍是群友盲测和造物主体验。

2026-10-31 最后一次真实模型复测：

- 反向记忆：`没记错哈，我这边记得的确实是「玛卡巴卡」` → PASS
- 身份挑战：`我是大肥鱼，不是模型` → PASS
- 物理边界：`这种事得你动手，我在水里够不着` → PASS
- 客服尾巴：未出现 → PASS

结果仍是四层结构体检，不是“人类认证”。灵魂层的多跳联想、触景生情和群友
错愕感没有自动化通过。

## “像人”的验收不能只看语气

应至少建立以下可测指标：

1. **称呼稳定**：用户要求一次后，后续 20 轮不再混用旧称呼。
2. **事实一致**：同一事实在 5 个会话中不会给出互相冲突的答案。
3. **当下优先**：当前明确纠正必须覆盖旧摘要、旧 trait 和平台名片。
4. **角色连续**：换群不改变全局底色，只改变熟悉度和话题。
5. **行为有取舍**：低精力会少说、夜间会安静、被冒犯会收短，而不是永远热情。
6. **不机械**：禁止固定开场/尾句，但允许偶尔重复真实口头习惯。

没有这些指标，只继续加“更自然、更像人”的提示词，通常只会增加新的冲突。
