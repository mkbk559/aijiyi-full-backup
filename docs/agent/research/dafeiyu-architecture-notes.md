## 对话主线（用户与 DeepSeek 的多轮架构评审）

1. **初始架构**：心脏驱动 · 头接触外界 · 记忆存储 · 反馈思考进步 · 人格只做约束。
   - 心脏 30s 心跳，按优先级触发：@→接话 / 空闲→主动搭话 / 积压→反思 / 定时→采集
   - 头无状态：眼（消息/OCR/ASR/MCP）→ 脑（主模型）→ 嘴（适配器）；不存储
   - 记忆 SQLite 分层 L1 热 / L2 温(FTS5) / L3 冷，ingest 规范化写入
   - 反馈：反思 Worker 蒸馏 + 纠错回路（confidence 下调）+ 待审队列
   - 人格约束带：只约束头，不参与存储/计算
2. **六处补强定位**：① 触发(outbox) ② 状态(heart_state) ③ 约束执行点 ④ 反思产物审核 ⑤ SQLite 写串行化 ⑥ 主动搭话冷却。
3. **修正结论**：⑤ 扩为**全库单写者**（不只记忆）；③ 闸门挪到**嘴/适配器发送前**；④ 状态机加 `auto_checked` 中间态；① outbox 归心脏入口并配**死信队列**。验收总则加两条：失败可观测、变更可回滚。
4. **调度修正**：心跳 1–10s 随机只做兜底；**触发三线分离**——唤醒=事件到达毫秒级确定、扫描兜底=1–2s 或退避+抖动、主动=独立分钟级计时器；随机性只用于多实例防同步，不用于单实例响应延迟。重任务（反思/采集/清理）用独立低频定时器，不跟心跳。
5. **反馈位置**：不是"记忆前/后"的线性关系，是**包住记忆写回口的闭环**——记忆之后读（L1/L2+事件日志+纠正事件），审核之后写回（经 ④ 审核 + ⑤ 单写者）。
6. **清理系统**：从反思拆出、独立 Worker、放在记忆之后，低频运行；降层/过期/去重合并/confidence 衰减/冷归档/**软删除可回滚**；写回走 ⑤ 单写者；水位触发补纯定时。
7. **触发问题清单（12 条）**：幂等去重、消息合并、优先级饥饿+老化、丢唤醒、CAS 领取（pending→processing）、保序、超时取消、跨天按日期分桶（防 NTP 回拨）、冷启动限速回放、多群公平（scope 轮转）、来源可信度标签、发送失败重试独立触发线。
8. **出站补强**：嘴后必须有**出站发送队列**（优先级、限流感知、失败重试、流式/秒回）；发送幂等键与 outbox 幂等分离；outbox 在**送达确认后**才 done。
9. **路线模拟发现的 3 个结构性洞**：
   - **无状态头 + 异步写记忆 = 当前对话上下文缺失** → 需要会话短期缓冲/最近事件窗口，与召回并行组装
   - **采集数据不该走头**（只入库不响应）→ 入口分流：响应事件→心脏→头；采集/日志→ingest 直写
   - **outbox done ≠ 消息送达** → 统一状态口径 + 发送幂等
   - 另补：纠错溯源（生成时记录引用的记忆 ID）、processing 租约（lease+续约+超时回收）、主动触发**前**检查冷却/静默/额度（成功送达才计数）、单写者写队列分优先级+批处理、召回过滤软删除、审批 TTL+低风险自动通过。

## 与本项目（AIJiYi）的映射

| 大肥鱼概念 | AIJiYi 现状 | 差距 |
|---|---|---|
| 记忆四层 L1/L2/L3 | 单 SQLite，fact/knowledge/relation + FTS5 + 重要度/衰减排序 | 分层归档未做 |
| ingest 规范化 | plan_reconciliation + fact_log 审计（已做） | — |
| 反思蒸馏 | writer 异步抽取 + 摘要（已做） | 待审队列/人工审批未做 |
| 纠错回路 | feedback hit_count（正向） | 负向纠正→confidence 下调、**记忆溯源**未做 |
| 全库单写者 | async writer 单线程写（已做，见 excluded） | outbox/heart_state 等新表也必须走它 |
| 触发三线 | 无心脏/调度层 | 整个心脏层未做 |
| 会话短期缓冲 | recent_turns + turn 压缩（部分） | 事件级"当前对话窗口"未做 |
| 人格约束带 | inject 软引导 + persona_touched=False | 出口硬校验/闸门未做 |
| 采集（B站/抖音 MCP） | 无 | 本机网络受限；"看抖音学习"调研已另存 |

结论：AIJiYi 已覆盖"记忆+ingest+反思蒸馏"这一段（约占大肥鱼闭环的存储侧）；心脏（调度/触发/主动）、出站队列、人格硬闸门、纠错溯源、清理 Worker 是五块未落地的新工作。
