# 大肥鱼素材够不够 RVC 训练门槛（2026-11-02 实测）

> 全部数字来自落盘脚本输出：`tools/voice_dataset_check.py` → `.tmp/voice-check/report.json`，
> `tools/voice_bgm_check.py` → `.tmp/voice-check/bgm.json`。
> 分离用 `voice-engine/models/UVR-MDX-NET-Voc_FT.onnx`（已有模型，未下载新东西）。

## 1. 结论

**够。** 用现成的整段人声（16.0 分钟）切一遍，有效语音约 **10.1 分钟**，正好过 RVC 官方「≥10 分钟低底噪」门槛；
现成的 92 段切片只有 **9.35 分钟**，差 0.65 分钟——**不要用老切片训练，用整段重切**。

## 2. 数字

### 2.1 现有切片 `data/voices/dafeiyu/dataset_v2/clips/`（92 段）

| 指标 | 值 |
|---|---|
| 总时长 | **9.5 分钟**（569.9 s，全部 44.1 kHz 单声道 16-bit） |
| 过线（≥3 s 且 SNR ≥15 dB 且削波 ≤1%） | 91 段 / **9.35 分钟** |
| SNR（同文件语音帧 vs 静音帧） | 中位 **32.0 dB**，最低 13.2，最高 47.1 |
| 最短/异常片段 | 无（`<2 s` 的 0 个） |
| RVC 门槛（10 分钟） | **差 0.65 分钟** |

⚠ 这个 SNR 只说明**文件内动态范围**，不能证明"没伴奏"——BGM 铺满整段时会被算进"语音"。

### 2.2 伴奏能量（两个 stem 的比值，才是 BGM 的真证据）

`bgm_ratio_db = 20·log10(rms(伴奏) / rms(人声))`：

| 分类 | 段数 |
|---|---|
| 干净（≤ −20 dB） | **0** |
| 轻微（−20 ~ −10 dB） | 1 |
| **伴奏很响（> −10 dB）** | **91** |

中位 **+1.5 dB**，最大 +9.9 dB。

→ 原素材（带 BGM 的视频）伴奏能量和人声**一样响**。所以：
1. **分离是必须的**，不能拿原片直接训；
2. 分离质量直接决定训练上限，**要人耳抽查**（我听不了，只能给你文件）；我们的 SNR 指标量不出音乐残留。

### 2.3 整段人声 `data/voices/dafeiyu/separated/source_normalized_(Vocals).wav`

| 指标 | 值 |
|---|---|
| 时长 | **16.0 分钟**（957.8 s，44.1 kHz 立体声，161 MB） |
| 峰值 / 削波 | −4.2 dBFS / **0%** |
| SNR | **57.9 dB** |
| 静音占比 / 语音帧占比 | 27.0% / 63.2% |
| **折算有效语音** | **≈ 10.1 分钟** |

这条是之前就分离好的整段人声，**比 92 段切片更值得做训练源**：无削波、底噪极低、覆盖完整。

## 4. 怎么办（建议顺序）

1. **用 `separated/source_normalized_(Vocals).wav` 重切**成 3–10 s 片段（RVC 自带 slicer，也可用 `tools/` 里现成逻辑），
   这次切片质量比老的 92 段更可控；预计 **10.1 分钟**有效语音。
2. **人耳抽查** 5–10 段切片（我给出路径），确认没有音乐残留/他人说话。
3. 装 RVC（`tools/engine_install_rvc.ps1`，dry-run 先行），用上面切片训一个大肥鱼模型（4 GB 卡先跑低显存档）。
4. 训出来的模型同时给"说话"（`postprocess.command` 走 CLI）和"唱歌"用；Seed-VC 已删除，见
   `seed-vc-integration-archive.md`。
